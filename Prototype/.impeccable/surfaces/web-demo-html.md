Scope: all SIMAK web surfaces (web/index.html, web/demo.html, web/evaluasi.html, shared web/style.css + web/common.js) and the generated accessible HTML (simak/output.py). Visitor mode: Operate.

Audience and job: competition judges watching a 15-minute projected demo (Demo Gerbang first, then Remediasi & Tinjauan, close on Evaluasi); credible as a daily ULD review tool. Must avoid: glossy AI-startup look, rigid government-form look, small/low-contrast text on a projector, decoration outranking evidence.

## Direction contract

THESIS: Every document element is a numbered library catalog card; every gate check and ULD decision is a dated stamp on that card's slip. Refuses the generic grey SaaS dashboard with coloured pills.

OWN-WORLD: Buckram-green rail (#1F4D3A) as the shell; cool white card stock ground (#F3F6F4) with white cards topped by a 5px catalog red rule; faint blue ruling only inside description text blocks; stamp violet (#5B3FA0) for passed checks and ULD decisions, catalog red (#B3261E) for failures; held state = violet diagonal hatch plus words. Atkinson Hyperlegible Next for text, Atkinson Hyperlegible Mono for numbers and call numbers. Flat colour, no gradients except ruling/hatch, no glow.

STORY: Judges see B2 publish a wrong number while SIMAK holds it with a readable reason; then see the same card system queue held elements for ULD; then read the frozen numbers.

FIRST VIEWPORT: Demo Gerbang. Left rail: SIMAK wordmark, three nav items, poster-scale proof figure 440/440 at bottom. Main: title, chart picker + Jalankan + four injection buttons in one bar; below, two equal halves Sisi A (B2) and Sisi B (SIMAK), each a catalog card with verdict band, ruled description with marked numbers, and a stamp slip. Chart and reference table sit below the halves.

FORM: Kartu Katalog Perpustakaan, position 7 of the grounded list, seed key edf5091c. Signature move: check stamps on the card slip (cF, cδ, cA, cL, ULD) rotated slightly, appearing in sequence when a run completes; raises: hatch for held, poster numerals, flat fields, one call number per element across pages, equal halves, focus dims rest of queue.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
